# EasyCopy

선택한 텍스트를 드래그 종료 시 복사하고, 필요한 사이트에서만 복사 방지를 해제하는 Chrome Manifest V3 확장 프로그램이다.

## 설치

1. 크롬에서 `chrome://extensions`를 연다.
2. 오른쪽 위의 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 선택한다.
4. `C:\project\javascript\easycopy` 폴더를 선택한다.
5. 확장 프로그램 메뉴에서 EasyCopy를 고정한다.
6. 설치 전에 열어 둔 웹페이지를 새로고침한다.

확장 프로그램 실행에는 Node.js 설치나 빌드가 필요 없다. Select Copy / Superb Copy를 함께 사용하면 같은 선택 이벤트가 중복 처리될 수 있으므로 EasyCopy를 사용할 때는 기존 확장을 꺼 둔다.

## 사용

EasyCopy 아이콘을 누르면 다음 설정을 변경할 수 있다. 팝업 상단에는 설치된 확장 프로그램의 버전을 표시한다. 설정은 이 브라우저의 로컬 저장소에 저장되며 열린 페이지에도 즉시 적용된다.

| 옵션 | 기본값 | 적용 범위 | 동작 |
| --- | --- | --- | --- |
| 복사 방지 해제 | 꺼짐 | 현재 사이트 | 텍스트 선택, 드래그, 우클릭, 수동 복사를 막는 일반적인 JS / CSS 제한을 해제함 |
| 드래그 후 자동 복사 | 켜짐 | 모든 사이트 | 왼쪽 버튼을 누르고 텍스트를 드래그한 뒤 버튼을 놓으면 일반 텍스트로 복사함 |
| 더블클릭 선택도 자동 복사 | 켜짐 | 모든 사이트 | 더블클릭으로 선택한 단어, 트리플클릭으로 선택한 문단도 자동 복사함 |
| 끝 공백과 줄바꿈 제거 (더블클릭 하위 옵션) | 켜짐 | 모든 사이트 | 더블클릭 / 트리플클릭으로 복사할 때 끝의 공백과 줄바꿈을 제거함 |
| 입력란에서도 자동 복사 | 꺼짐 | 모든 사이트 | 텍스트 입력란, 여러 줄 입력란, 웹 편집기에서 선택한 텍스트도 자동 복사함 |
| 복사 알림 | 켜짐 | 모든 사이트 | 복사 결과를 마우스 옆에 잠시 표시함 |

- 복사 방지 해제는 정확히 일치하는 호스트 이름별로 저장한다. `example.com`과 `sub.example.com`은 별도 사이트로 처리한다.
- 해당 사이트 안의 iframe에는 상위 페이지의 복사 방지 해제 설정을 적용한다.
- 복사 방지 해제와 자동 복사는 서로 독립적이다. 자동 복사를 끄고 복사 방지만 해제하여 수동으로 복사할 수 있다.
- 복사 방지 해제를 끄면 삽입한 CSS를 제거하고 이벤트 차단을 중지한다. 사이트의 원래 이벤트 핸들러를 삭제하지 않는다.
- 복사 후에도 텍스트 선택을 유지한다. 선택한 텍스트의 공백과 줄바꿈을 보존한다.
- 입력란 자동 복사는 기본적으로 꺼져 있다. 입력란 안의 텍스트 선택, 편집과 Ctrl+C 수동 복사는 유지한다. 읽기 전용 입력란은 일반 본문처럼 자동 복사한다.
- 더블클릭 선택 복사는 드래그 후 자동 복사가 켜져 있을 때만 동작하며, 입력란 자동 복사 옵션도 동일하게 적용한다. 브라우저가 함께 선택한 단어 뒤 공백과 문단 끝 줄바꿈은 기본적으로 제거하여 복사하며, 화면의 선택 영역은 그대로 둔다. 드래그로 선택한 텍스트에는 적용하지 않는다.
- 키보드 선택, 단순 클릭, 오른쪽 클릭만으로는 자동 복사하지 않는다. 비밀번호 입력란은 자동 복사 대상에서 제외한다.
- Chrome 내부 페이지와 Chrome 웹 스토어에서는 브라우저 제한으로 실행되지 않는다.
- 이미지 / 캔버스 안의 글자처럼 원래 선택 가능한 텍스트가 없는 콘텐츠에는 적용되지 않는다.

## 구현

- `manifest.json`: 프로젝트 루트에서 확장을 로드하기 위한 진입 설정을 정의함.
- `extension/content.js`: 드래그 감지, 텍스트 추출, 선택 이벤트 보호, 복사 알림을 담당함.
- `extension/background.js`: 사용자 우선순위 CSS 삽입 / 제거와 클립보드 대체 경로를 담당함.
- `extension/offscreen.js`: HTTP 페이지나 클립보드 API 사용이 제한된 프레임의 복사를 지원함.
- `extension/popup.html`, `popup.css`, `popup.js`: 현재 사이트와 전역 설정 UI를 제공함.
- `extension/shared.js`: 기본 설정, 입력값 정규화, 사이트 식별 로직을 공유함.

설정과 복사는 로컬에서 처리한다. 외부 서버 호출, 복사 기록 저장, 구독 제한은 없다. 설치된 Select Copy 1.0.0 / Superb Copy 1.0.2의 동작 방식을 참고하여 별도로 구현했다.

복사 방지 해제가 켜진 사이트에서는 본문의 선택 관련 마우스 이벤트가 페이지 스크립트에 전달되지 않는다. 입력란, 편집기, 버튼 등의 상호작용은 유지한다. 사이트 고유의 드래그 UI를 사용할 때는 해제 옵션을 끌 수 있다.

## 개발 / 검증

```powershell
npm ci
npx playwright install chromium
npm test
```

- `npm run test:unit`: 설정 정규화, 사이트 식별, 드래그 / 더블클릭 판별을 검증함.
- `npm run test:e2e`: 별도 Chromium 프로필에 실제 확장을 로드하여 복사, 더블클릭 / 트리플클릭 복사, 입력란 자동 복사 제외 / 허용, 옵션 전환, 복사 방지 해제 / 복원, HTTP 복사, iframe, 팝업 UI를 검증함.
- `npm run icons`: 확장 아이콘을 다시 생성함.

코드를 수정한 뒤에는 `chrome://extensions`의 EasyCopy 새로고침 버튼을 누르고 대상 웹페이지도 새로고침한다.
